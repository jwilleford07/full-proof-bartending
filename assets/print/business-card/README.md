Print recommendation:

- Preferred: MOO Standard Business Cards, uploaded full design, matte or soft-touch style.
- Use standard 3.5 x 2 in trim with 0.125 in bleed. These files are already sized to 3.75 x 2.25 in.
- Use the SVG masters for final print export when possible because the text stays crisp. Use the PNGs for upload only if the printer requires raster artwork.
- Use the tuned `*-print-cmyk.pdf` front/back files when the printer specifically requests two separate CMYK files.
