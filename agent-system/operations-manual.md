# Full Proof Bartending — Operations Manual

Portable reference for **intake → consult → pack → execute → proof → follow-up**. Goal: polished, repeatable, low-stress events. Bar reads intentional from guest side and behind the bar—no card-table energy.

---

## 1. Inquiry workflow

Use from first message until deposit clears and date is locked.

| Stage | Owner | Actions |
|-------|-------|---------|
| **1. Acknowledge** | Ops | Reply within business hours; confirm you saw date, location type, guest count (estimate OK), event type. |
| **2. Qualify** | Ops | Confirm mobile bar fit (space, power expectations, water source if applicable). Flag red flags early (illegal venues, unrealistic guest:bartender ratios). |
| **3. Schedule consult** | Ops | Book call or detailed async questionnaire—whatever closes fastest without skipping essentials (Consultation checklist below). |
| **4. Quote** | Ops | Send quote using `client-quote-response-template.md`; specify hours, staffing, what’s included (setup, ice program, glassware philosophy). |
| **5. Contract + deposit** | Ops | Agreement out; **50% deposit** to hold date; calendar block only after deposit policy satisfied. |
| **6. Prep triggers** | Ops | After booking: shopping list timeline, internal prep list, pack list draft from menu + headcount. |

**Same-day inquiry shortcut (busy night):** Send short acknowledgement + two booking slots for consult + “approx guest count + indoor/outdoor bar?” Never ghost—premium is responsiveness.

## 2. Consultation checklist

Complete **before** final quote or menu lock. Check each box.

### Event basics
- [ ] Date, start time, **official end time**, venue name + address
- [ ] Indoor / outdoor / both; rain or heat contingency if outdoors
- [ ] Guest count (committed + realistic max)
- [ ] Host priorities: speed vs. cocktail theater vs. specific vibes
- [ ] Kids/teens present (service implications, NA expectations)

### Bar placement & logistics
- [ ] Preferred bar footprint confirmed or site visit/parking photo scheduled
- [ ] Electrical: dedicated circuit expectations communicated (mobile bar power needs)
- [ ] Water access noted (hose bib, sink proximity, fills allowed)
- [ ] Load-in path: stairs, elevators, distance from parking—**time budget for carry**
- [ ] Venue rules: noise cutoff, teardown deadline, trash/recycling expectations

### Beverage program
- [ ] Client-provided alcohol model confirmed (they shop from your list)
- [ ] Menu direction: classics-only, signatures, wine/beer ratios
- [ ] Batch-friendly vs. all à la minute—aligned with staffing level
- [ ] NA options expectation (complex NA cocktails vs. sodas/mocktails)
- [ ] Ice-sensitive drinks identified (large rocks program, garnishes)

### Risk & clarity
- [ ] Shot-only / irresponsible service expectations shut down politely if needed
- [ ] Tip jar policy / gratuity expectations clear if relevant
- [ ] Parking passes, vendor meals, green room—confirmed or waived

### Close
- [ ] Quote tier matches consult outcomes (hours + bartenders + extras)
- [ ] Shopping list delivery date agreed (typically X weeks/days before event per your norm)

## 3. Service timeline (typical private event)

Adjust load-in for venue difficulty. Build slack—**running late reads cheap**.

| Phase | Timing (guide) | Notes |
|-------|------------------|-------|
| **Travel + arrival** | T−setup | Confirm POC on site; scout load-in before unpacking |
| **Load-in & staging** | Start | Dollies, floor protection if needed; quiet professionalism |
| **Build bar** | Core setup | Power, water, lighting, rail layout—guest-ready silhouette |
| **Ice program** | Parallel | Clear ice staged; backups labeled; melt management planned |
| **Menu QA** | Pre-open | Taste batched components if any; garnish mise verified |
| **Soft open / water line** | Pre-guest | Staff hydrated; radios/phones silenced; trash/recycling staged |
| **Active service** | Contract hours | Standards in Setup & strike checklist |
| **Last call choreography** | Per agreement | Align with host; clean messaging to guests |
| **Breakdown begins** | Post-last pour | Consolidate bottles per host plan; secure valuables |
| **Strike** | See Setup & strike checklist | Leave venue cleaner than found where policy allows |
| **Departure** | Final | Photo proof done if not earlier (Proof-capture checklist); confirm nothing left |

## 4. Event pack list

Pack by **zone** so unload matches setup order. Customize per menu; this is the default skeleton.

### Bar core (mobile unit accessories)
- [ ] Mobile bar keys / tie-downs / leveling wedges if used
- [ ] Extension cords rated for load + **one spare**
- [ ] Power strips / GFCI awareness per venue
- [ ] Fresh water vessels + hoses/adapters as applicable
- [ ] Drain buckets / grey-water plan / absorbent towels
- [ ] Bar mats (service + spill)
- [ ] Trash + recycling bags + slim jims / ties

### Ice & temperature
- [ ] Clear ice stock for service + **backup cube sleeve/plan**
- [ ] Ice tote/coolers; scoop(s)—**never glass**
- [ ] Thermometer(s) if batching dairy/citrus-heavy prep

### Tools & smallwares
- [ ] Shakers (weighted tins set), mixing glasses, bar spoons (short + long)
- [ ] Jiggers (duplicate sizes), Hawthorne + fine mesh strainers
- [ ] Citrus press, channel knife/peeler, cutting boards (color-coded if cross-allergen)
- [ ] Knife roll + steel; gloves / sanitizer / spray bottles (labeled)
- [ ] Speed pourers + corks/stoppers
- [ ] Muddlers, bitters bottles service-ready

### Glassware / service
- [ ] Tossware or contracted glassware counts **+10% buffer**
- [ ] Wine/beer vessels if in scope
- [ ] Garnish picks / napkins / straws policy compliant with venue

### Garnish & mise (menu-dependent)
- [ ] Citrus washed/cut timing plan (avoid oxidized lime circus)
- [ ] Herbs/salt/rims/chocolate/other—labeled deli containers
- [ ] Backup garnish cooler pack for outdoor heat

### Backup / emergencies
- [ ] Toolkit (tape, zip ties, multi-tool, flashlight/headlamp)
- [ ] Extra bar towels (dark), apron(s)
- [ ] Backup opener, spare pour spouts
- [ ] First aid basics appropriate for staff use

### Admin / proof
- [ ] Printed run-of-show / menu card copies if used
- [ ] Clipboard: venue POC, wifi, emergency egress note

## 5. Setup & strike checklist

### Setup (guest-facing priority first)
- [ ] Floor stable—no rocking rail; cords dressed **tripping hazard zero**
- [ ] Guest sightlines: labels faced away, clutter hidden, symmetry intentional
- [ ] Running water live; rinser behaving; towels staged dirty/clean
- [ ] Lighting fixes shadows on bottles/glasses—premium reads in photos
- [ ] Ice wells stocked; melts planned (swap cadence)
- [ ] Trash/recycling reachable without crossing guest lanes
- [ ] Tools dry and organized; no “yard sale” between tickets
- [ ] Non-alcoholic station equivalent care (glass, ice, garnish)

### During service (standards snapshot)
- [ ] Smile at approach; acknowledge before pour
- [ ] Confirm order on loud floors; upsell hospitality not pressure
- [ ] Glasses never empty on water/soft drinks when host expects it
- [ ] Cut-off policy friendly, firm, aligned with host

### Strike
- [ ] Sort client product for host (sealed vs. discard) per prior agreement
- [ ] Drain lines; wipe bar; bag compostables/trash per venue
- [ ] Pack wet gear separately; **no moldy towels in closed totes overnight**
- [ ] Final walk: under bar, coolers, ice bins, garnish traces
- [ ] Thank POC by name; confirm departure time respected

## 6. Proof-capture checklist

Capture **during** setup or golden-hour pause—not only after messy service.

### Photos / short video (minimum viable content)
- [ ] Wide shot: bar in environment (shows intentional footprint)
- [ ] Hero detail: clear ice in glass + cocktail hero light
- [ ] Hands-at-work pour (blur faces if no releases)
- [ ] Garnish tray or organized rail “behind the scenes” tasteful crop
- [ ] Toast or candid energy (if host approves **in the moment**)

### Metadata to record same day
- [ ] Venue city + event type tag (internal)
- [ ] Menu item names actually served
- [ ] Anything that broke and how you recovered (lesson for SOP)

### Consent & safety
- [ ] Verbal/text OK from host for posting if guests identifiable
- [ ] No minors holding alcohol in frame

---

## 7. Post-event follow-up

Within **48 hours** unless host requests otherwise.

- [ ] Thank-you message (warm, specific detail from their night)
- [ ] Final invoice / balance handling if applicable
- [ ] Lost & found handoff noted
- [ ] Internal debrief: pack list misses, timing, vendor issues
- [ ] Review request: only if earned; link + one-sentence ease (“Two taps on Google helps a ton”)
- [ ] CRM/note: anniversaries, employee party potential, referrer tag

---

## Quick reference — ice & cleanliness

- Ice is part of **one system** with water, glass, and light—never an afterthought.
- When in doubt: more spare towels, more spare ice backup, more time in load-in estimate.
