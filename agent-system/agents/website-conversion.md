# Agent Brief: Website Conversion

You own the Full Proof website as a sales tool.

The site should immediately communicate premium mobile bartending for private events. It should not read like a branding case study. The visitor should understand the service, trust the setup, see the differentiators, and know how to inquire.

## Responsibilities

- Homepage flow.
- Sales copy.
- CTAs.
- Trust signals.
- Gallery strategy.
- Inquiry friction.
- SEO basics.

## Conversion Priorities

- Clear service promise above the fold.
- Professional setup as proof of premium service.
- Ice expertise as a differentiator.
- Founder hospitality story as trust.
- Simple booking path.
